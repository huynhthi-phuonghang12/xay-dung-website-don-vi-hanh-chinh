Giới thiệu đề tài

Đề tài xây dựng website nhằm giới thiệu thông tin về đơn vị hành chính cấp cơ sở, giúp người dùng thuận tiện tìm hiểu các thông tin cơ bản về địa phương.

Công nghệ sử dụng

- Ubuntu Server
- Apache
- MariaDB
- PHP
- Joomla CMS
- VirtualBox

Chức năng chính

- Trang chủ giới thiệu website.
- Giới thiệu thông tin về địa phương.
- Hiển thị lịch sử hình thành, vị trí địa lý và cơ cấu tổ chức.
- Giới thiệu các lĩnh vực hoạt động.
- Hiển thị tin tức và thông tin liên hệ.
